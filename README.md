# 🩺 AI Medical Consultation & Voice Intake Platform

An AI-powered full-stack healthcare platform designed to streamline patient intake using voice recognition, intelligent medical assessment, and real-time consultation tracking.

---

## 🛠️ Tech Stack & Architecture

- **Frontend**: React (Vite), React Router, Web Speech API, Tailwind CSS
- **Backend**: Java 17, Spring Boot, Spring Security (JWT), Hibernate / Spring Data JPA
- **AI Integration**: OpenRouter API (LLM integration for dynamic intake analysis)
- **Database**: MySQL 8.0
- **Containerization & Web Server**: Docker, Docker Compose, Nginx

---
